# Orbit Daily

NASA의 [Astronomy Picture of the Day(APOD)](https://apod.nasa.gov/)를 날짜별로 감상하고 브라우저에 저장하는 한국어 웹 앱입니다.

## 기능

- 오늘 또는 선택한 날짜의 천문 사진·영상과 해설 조회
- 이전/다음 날짜 및 랜덤 날짜 탐험
- 고해상도 원본 보기
- `localStorage` 기반 개인 컬렉션
- 서버 프록시와 메모리 캐시를 통한 API 키 보호 및 호출 절약
- 모바일 반응형 UI

## 실행

Node.js 20 이상이 필요하며 외부 패키지는 사용하지 않습니다.

```bash
cp .env.example .env
# .env에 NASA_API_KEY를 입력하거나 DEMO_KEY로 바로 실행
npm start
```

브라우저에서 <http://localhost:3000>을 엽니다. `.env` 파일은 Node가 자동으로 읽지 않으므로 키를 사용할 때는 다음처럼 환경변수로 전달합니다.

```bash
NASA_API_KEY=your_key npm start
```

무료 API 키는 [NASA Open APIs](https://api.nasa.gov/)에서 발급할 수 있습니다.

앱 상단의 **API 키 설정** 버튼에서도 발급받은 키를 입력할 수 있습니다. 입력한 키는 현재 브라우저 탭의 `sessionStorage`에만 보관되고, API 요청 시 서버를 거쳐 NASA에 전달됩니다. 키 없이 사용하면 `DEMO_KEY`가 적용됩니다.

날짜를 연속으로 선택하면 진행 중이던 이전 요청은 자동으로 취소되고 가장 마지막 요청의 결과만 화면에 표시됩니다.

사진 옆 설명의 `EN`/`한글` 버튼으로 원문과 한국어 번역을 전환할 수 있습니다. 한국어를 처음 선택할 때 번역 서비스를 호출하며, 같은 설명의 번역 결과는 서버 메모리에 캐시됩니다.

## 개선 로드맵

Orbit Daily를 더 안정적이고 편리하게 만들기 위해 다음 기능을 순차적으로 검토합니다. 우선순위는 현재 외부 API 의존성과 사용자 체감 효과를 기준으로 정했습니다.

### 1. 번역 서비스 안정성 개선

- 번역 요청에 명시적인 제한 시간과 제한적인 재시도 적용
- 번역 공급자를 환경변수로 선택할 수 있도록 구성
- 번역 실패 시 원문을 유지하고 설명 영역에 재시도 버튼 제공
- 서버가 재시작되어도 유지되는 영구 번역 캐시 검토

### 2. 오류 유형별 안내 및 재시도 UI

- API 키 오류, 사용량 제한, 네트워크 오류 및 외부 서비스 장애를 구분해 표시
- 오류 화면에 **다시 시도**와 **API 키 확인** 동작 제공
- 네트워크 연결이 복구되었을 때 안전한 자동 재시도 지원

### 3. 서버 요청 타임아웃과 재시도 정책

- NASA 및 번역 API 요청에 각각 적절한 타임아웃 적용
- 일시적인 네트워크 오류와 `5xx` 응답만 제한적으로 재시도
- 인증 오류와 `429 Too Many Requests`는 재시도하지 않고 정확한 상태 전달
- upstream 타임아웃을 `504 Gateway Timeout`으로 구분

### 4. 컬렉션 검색·필터·정렬

- 저장한 APOD의 제목 검색과 날짜 범위 필터
- 사진과 영상 구분
- 최신순 및 오래된순 정렬
- 사용자 태그와 즐겨찾기 분류

### 5. 컬렉션 내보내기·가져오기

- 브라우저에 저장된 컬렉션을 JSON 파일로 백업
- 백업 파일 가져오기와 중복 날짜 자동 병합
- 잘못된 파일 형식과 손상된 데이터 검증

### 6. 공유 가능한 날짜별 URL

- `?date=2024-04-08` 형태로 현재 APOD 날짜를 URL에 반영
- 공유 URL로 진입했을 때 해당 날짜를 즉시 표시
- 브라우저 뒤로 가기와 앞으로 가기 지원
- 현재 APOD 링크 복사 버튼 제공

### 7. 앱 내부 이미지 뷰어

- 새 탭 대신 라이트박스에서 원본 이미지 감상
- 확대·축소와 드래그 이동
- 키보드와 터치 제스처를 이용한 날짜 탐색
- 이미지 다운로드 및 일반·고해상도 전환

### 8. 천체 정보와 관련 자료

- 설명에서 주요 천체와 관측 대상을 쉽게 찾을 수 있도록 보조 정보 제공
- 관련 NASA 자료, APOD 검색 및 천문 데이터베이스 링크 연결
- 비슷한 주제의 과거 APOD 탐색 기능 검토

### 9. 접근성과 키보드 조작 개선

- 언어 선택과 저장 상태에 `aria-pressed` 등 명확한 접근성 상태 적용
- 동적 로딩 및 번역 상태를 스크린 리더에 전달
- 모달 포커스 복귀, 명확한 `:focus-visible` 스타일 및 키보드 날짜 이동 지원
- `prefers-reduced-motion`과 이미지 로딩 실패 대체 UI 지원

### 10. PWA와 오프라인 지원

- 홈 화면 설치를 위한 Web App Manifest 제공
- 앱 셸과 최근 본 APOD의 오프라인 열람 지원
- 저장 공간을 고려해 최근 항목 또는 썸네일 중심으로 캐시
- 네트워크 연결 상태와 새 버전 업데이트 안내

### 권장 구현 순서

1. **안정성:** 번역 안정성, 오류별 재시도 UI, 서버 타임아웃
2. **사용성:** 공유 URL, 컬렉션 검색·정렬, 컬렉션 백업
3. **완성도:** 이미지 뷰어, 접근성, PWA, 관련 천체 정보

첫 번째 소규모 개선으로는 외부 서비스가 필요 없고 기존 날짜 탐색과 자연스럽게 연결되는 **공유 가능한 날짜별 URL**을 권장합니다. 운영 안정성을 먼저 강화해야 한다면 **서버 요청 타임아웃과 오류별 재시도 UI**를 우선 구현합니다.
